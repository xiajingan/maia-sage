# 终端接入

Sage 在已验证的个人工作空间内提供「终端」入口。签发、登记与根隔离由 Mud 裁决，连接和能力观测由 Stem 提供。页面通过 [Mud 生成客户端](authentication.md#结构与依赖)发送空 JSON 签发命令并分页查询，使用当前 OIDC Bearer 和生成的运行时 Schema。

## 激活码

「添加终端」打开原生模态对话框并签发激活码。对话框将焦点置于「关闭」，支持 Escape 并恢复触发按钮的焦点。码保存在页面的局部内存，标注为「一次性激活码」，到期时间使用带 ISO `datetime` 的 `time` 元素。到期、关闭对话框、离开页面或切换会话均清除显示与局部状态。签发请求不并发、不自动重试，失败或过期后由用户重新生成。签发仅更新对话框，终端列表以服务端登记结果为准。

## 列表与会话边界

- 每页请求 20 条，用户可以沿服务端 cursor 前进或回到首页。首次加载、无终端、请求错误和保留上次结果的降级分别显示。错误仅使用本地中文提示和通过契约校验的关联编号。
- 单页按请求完成后间隔 3 秒轮询，初次读取后最多 60 次自动读取，手动刷新或翻页重新开启一个窗口。每次 HTTP 请求限时 10 秒。离开页面取消正在处理的读取和签发，并停止计时器。
- 会话控制器比较 epoch 和当前 SessionView 引用，丢弃旧请求的结果与拒绝。当前会话收到 401 或 403 时沿用既有清理和退出路径，终端页面随会话卸载。
- 列表按服务端返回的字符串 terminalId 标识条目。已激活与连接状态独立，缺少观测显示「待确认」。已观测且服务端标记不符合资格时显示当前不能执行任务及已知最低 Celt 版本。能力采用操作 ID，`wecom.send_message` 显示为「发送文本消息」。
