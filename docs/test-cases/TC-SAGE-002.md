# TC-SAGE-002 终端列表、激活码和旧会话隔离

## 来源

US-009 AC-01、AC-02、AC-04、AC-05、AC-06、AC-07 的 Sage 行为，以及迟到响应和轮询退出边界。

## 前置条件

用户已登录个人工作空间。客户端测试验证生成契约；浏览器测试向真实 Chrome 注入合成 API 响应。

## 步骤与预期结果

1. 从工作空间打开「终端」，依次收到加载、空列表、故障和恢复结果。界面区分状态，显示安全关联编号，刷新失败时提示上次结果。
2. 使用键盘打开「添加终端」。模态对话框显示一次性码和 ISO 到期时间，未登记的列表保持原样。Escape 关闭后码从页面移除并恢复焦点。到期清除码，用户可重新生成，浏览器存储中没有码。
3. 提供已激活、在线、离线、低版本和无观测条目。连接、最后在线、两类版本和本机能力分别显示。低版本条目提示不能执行及最低版本。移动端长名称正常换行，翻页后只显示本页。
4. 在列表或签发未返回时离开页面，或在旧终端请求未返回时换会话。旧结果不能恢复页面数据，旧拒绝不能撤销新会话。连续停留到轮询上限后停止自动请求。
